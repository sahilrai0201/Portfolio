## ✨ Highlights & Features

- **⚡ Fast & Modern Architecture**: Built with Vite and React for near-instant page loads and smooth client-side interactions.
- **⌘ Command Palette (Ctrl+K / Cmd+K)**: Quick keyboard-driven navigation across sections, featured projects, and resume download.
- **💼 Interactive Project Showcase**: Detailed project deep-dives featuring architecture highlights, engineering decisions, and screenshot galleries.
- **🧩 Algorithmic Milestones**: Live tracking of 400+ DSA problems solved across LeetCode (1500+ rating) and GeeksforGeeks.
- **♟️ Chess & Analytical Spotlight**: A personal section highlighting tactical decision-making and pattern recognition through chess.
- **📄 Interactive Resume Modal**: In-browser resume viewer with quick PDF download and key qualifications.
- **📬 Working Contact Form**: Integrated with FormSubmit AJAX and mailto backup for direct recruiter outreach.

## 🛠️ Tech Stack

- **Frontend**: React 18, HTML5, CSS3 (Modern Glassmorphic Design System)
- **Icons & Visuals**: Lucide Icons, Custom SVG Badges, Canvas Confetti
- **Build Tool**: Vite
- **Deployment**: Render (Static Site, Auto-CI/CD from GitHub)

## 🚀 Running Locally

```bash
# 1. Clone the repository
git clone https://github.com/sahilrai0201/Portfolio.git

# 2. Navigate to directory
cd Portfolio

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev
```

Visit `http://localhost:5173` in your browser.
